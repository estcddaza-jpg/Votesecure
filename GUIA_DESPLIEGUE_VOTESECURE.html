1 Requisitos Previos del Sistema

Antes de iniciar el despliegue, verifique que su entorno de desarrollo cuente con el siguiente software instalado:

  • Node.js: Versión v18.x o superior (Recomendado v20+ LTS).
  • NPM: Versión 9.x o superior.
  • Navegador Web Moderno: Google Chrome, Microsoft Edge, Brave o Firefox.
  • Billetera Web3 (Opcional): Extensión o app móvil de MetaMask configurada.
  • Cuenta de Google: Para acceder a la consola de Firebase.
  • Cuenta de Netlify: Para el hosting estático de alta disponibilidad.

3 Configuración de la Base de Datos en la Nube (Firebase)

La persistencia y sincronización multi-dispositivo en tiempo real se gestiona mediante Google Cloud Firestore:

  1. Ingrese a console.firebase.google.com con su cuenta de Google.
  2. Haga clic en "Crear un proyecto" y asígnele el nombre (ej. vote-fesc).
  3. En el menú lateral, diríjase a Compilación → Firestore Database y haga clic en "Crear base de datos".
  4. Seleccione la ubicación predeterminada (ej. nam5 o us-central).
  5. Reglas de Seguridad: Seleccione "Iniciar en modo de prueba". Esto generará la siguiente regla para permitir lectura y escritura abierta durante la jornada electoral: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
  6. Registrar la Aplicación Web:
    • En el engranaje superior ⚙️ seleccione Configuración del proyecto → pestaña General.
    • En la sección "Tus apps", presione el ícono Web </>.
    • Asigne el alias votesecure y presione Registrar app.
    • Copie el objeto de configuración firebaseConfig obtenido:
    const firebaseConfig = {
  apiKey: "AIzaSyALnyvSqr8i4uJ8naO1xs9d0PujhQaKc5k",

4 Compilación y Despliegue del Frontend (Netlify)

4.1. Instalación de Dependencias y Compilación

Abra una terminal en el directorio frontend y ejecute:

# 1. Navegar a la carpeta frontend
cd voting-app/frontend

# 2. Instalar dependencias requeridas
npm install

# 3. Compilar el paquete optimizado de producción
npm run build
Salida de Compilación: El comando genera una carpeta llamada dist/ que contiene los assets minificados, el código CSS optimizado y el HTML listo para servir en cualquier CDN mundial.

4.2. Despliegue en Netlify (Método Inmediato por Netlify Drop)

  1. Inicie sesión en app.netlify.com.
  2. Acceda a su proyecto (ej. fancy-sunflower-aa05c5) y vaya a la pestaña Deploys.
  3. En la sección inferior que indica "Need to update your site? Drag and drop your site output folder here", arrastre y suelte la carpeta frontend/dist.
  4. El despliegue tarda aproximadamente 5 segundos en reflejarse con estado Published.
  5. Su sitio web estará disponible públicamente con certificado SSL automático (HTTPS).

5 Despliegue del Smart Contract (Solidity / Hardhat)

El núcleo de inmutabilidad reside en el contrato Voting.sol, ubicado en blockchain/contracts/Voting.sol.

5.1. Compilación del Contrato Inteligente

# Navegar al directorio blockchain
cd voting-app/blockchain

# Compilar contratos con Hardhat
npx hardhat compile

5.2. Despliegue a Red Local (Hardhat Node)

# Terminal 1: Iniciar nodo Ethereum local
npx hardhat node

# Terminal 2: Ejecutar script de despliegue
npx hardhat run scripts/deploy.js --network localhost

5.3. Despliegue a Red Pública Testnet (Sepolia)

Configure sus variables en blockchain/hardhat.config.js con su clave de infura/alchemy y su clave privada:

# Desplegar en red de pruebas Sepolia
npx hardhat run scripts/deploy.js --network sepolia

Una vez desplegado, copie la dirección resultante del contrato y el archivo ABI generado (artifacts/contracts/Voting.sol/Voting.json) al frontend.

6 Operación en Vivo del Comité Electoral

Fase Acción del Administrador Resultado en el Sistema
1. Ingreso Clic en botón "Acceso Consejo" → Clave: fesc2026. Se abre el panel institucional de administración.
2. Jornada En pestaña "Consejo de Votación", verificar que las urnas estén Abiertas. Habilita la recepción de votos en Firestore y Blockchain.
3. Candidatos En pestaña "Candidatos", inscribir los candidatos oficiales con sus lemas. Aparecen instantáneamente en la papeleta de todos los teléfonos móviles.
4. Votación Proyectar la pantalla principal con el Código QR visible. Los estudiantes escanean el QR, ingresan su cédula y sufragan en 10 segundos.
5. Escrutinio Presionar el botón "Resultados" en la barra superior. Muestra los gráficos de porcentaje y total de votos actualizados en vivo.
6. Auditoría Presionar "Auditoría" e ingresar el TXID Hash de un voto. Despliega el certificado digital de sufragio con marca de tiempo oficial.
